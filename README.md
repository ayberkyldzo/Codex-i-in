# Calculator GUI

This repository contains a simple GUI calculator written in C++ using Qt.
It displays a menu that lets you perform addition, subtraction, multiplication,
and division using pop-up dialogs.

## Building (macOS / Xcode)

1. Install [Qt 5](https://www.qt.io/download) on your system.
2. Run the following commands:

```bash
mkdir build && cd build
cmake .. && make
```

After building, you can run `./CalculatorApp` to open the window-based calculator.
